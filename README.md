# gbetkom-os
GBETKOM OS est un système d'exploitation conçu par KALIL COMPANY pour les PC 64 bits. Il est simple à installer, sécurisé dès le premier démarrage et multilingue. Il s'appuie sur une base Linux (Debian), reconnue pour sa stabilité, avec un bureau léger et moderne aux couleurs GBETKOM. Ses points forts : Applications en un clic...etc.
